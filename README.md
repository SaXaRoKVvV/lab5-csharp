# 1. Чтение и просмотр базы данных

### Текст задачи

Считать базу данных из Excel-файла `LR5-var10.xls` в коллекции объектов и реализовать просмотр содержимого таблиц в консоли.

### Алгоритм решения

1. Метод `ExcelService.Load(path)` открывает книгу через `WorkbookFactory.Create` и последовательно считывает три листа: `Движение товаров`, `Магазин` и `Товар`.
2. При просмотре таблицы (`ShowDatabase`) пользователь выбирает нужный лист (`1` — Движение товаров, `2` — Магазины, `3` — Товары) и количество первых строк (`0` — вывести все).
3. Вывод форматируется с помощью перегруженного метода `ToString()` в классах моделей.

### Проверка входных данных

- До загрузки файла действия с таблицами блокируются методом `CheckLoaded()`.
- Ошибки открытия файла перехватываются в `Program.cs` блоком `try-catch`.
- Ввод номера таблицы и лимита строк проверяется через `InputHelper.ReadInt`.

# 2. Удаление элементов (по ключу)

### Текст задачи

Реализовать удаление элемента из выбранной таблицы по первичному ключу.

### Алгоритм решения

1. Пользователь выбирает таблицу и вводит значение первичного ключа (`ID операции`, `ID магазина` или `Артикул`).
2. Для таблиц `Магазины` и `Товары` перед удалением выполняется проверка ссылочной целостности через `Any`: если в списке `Movements` есть записи с этим ключом, удаление отменяется.
3. Удаление выполняется методом `RemoveAll` с поиском по ключу (для строковых ID — без учёта регистра).

### Проверка входных данных

- При отсутствии записи с введённым ключом выводится соответствующее сообщение.
- Удаление магазина или товара, на который ссылается таблица движений, блокируется с пояснением причины.

# 3. Добавление элементов

### Текст задачи

Реализовать добавление новых элементов в таблицы базы данных.

### Алгоритм решения

1. Пользователь выбирает таблицу и последовательно вводит значения полей новой записи.
2. Перед добавлением проверяется уникальность первичного ключа через LINQ-метод `Any`.
3. При добавлении записи в `Движение товаров` дополнительно проверяется существование введённых `ID магазина` (`FirstOrDefault`) и `Артикула` (`Any`) в справочниках, а тип операции считывается через `InputHelper.ReadOperationType()`.
4. Новый объект добавляется в соответствующую коллекцию через `Add`.

### Проверка входных данных

- Дублирование первичного ключа отклоняется.
- Указание несуществующего магазина или артикула при добавлении операции отклоняется.
- Числовые поля и дата валидируются методами `InputHelper` до создания объекта.

- Поиск по названию района выполняется без учёта регистра.

# 7. Запрос 4 (три таблицы, одно значение)

### Текст задачи

Определить общий объём (в литрах) всех видов шампуней для волос, проданных магазинами, расположенными на улице Гагарина, за период с 14 по 22 июля 2023 года включительно.

### Алгоритм решения

1. Пользователь вводит часть названия товара (например, `Шампунь`), улицу (например, `Гагарина`), дату начала и дату окончания периода.
2. Метод `QueryService.GetSoldVolumeInLiters(_db, name, street, from, to)` соединяет таблицы `Movements`, `Shops` и `Products` через `Join`.
3. Записи отбираются по условиям: тип операции `Продажа`, дата в диапазоне `[from; to]`, адрес содержит указанную улицу, наименование товара содержит введённую подстроку, а единица измерения — `мл` или `л`.
4. Через `Sum` вычисляется суммарный объём с переводом миллилитров в литры (`/ 1000.0`).

### Проверка входных данных

- Если дата начала позже даты окончания (`from > to`), запрос не выполняется и выводится предупреждение.
- Корректность формата дат проверяется в `InputHelper.ReadDate`.

# 8. Сохранение изменений в Excel-файл

### Текст задачи

Реализовать сохранение внесённых изменений обратно в файл `LR5-var10.xls`.

### Алгоритм решения

1. Пользователь указывает путь сохранения или нажимает Enter для перезаписи текущего файла (`LR5-var10.xls`).
2. Метод `ExcelService.Save(_db, path)` формирует книгу Excel с тремя листами (`Движение товаров`, `Магазин`, `Товар`), записывает заголовки и выгружает актуальные данные из коллекций.

### Проверка входных данных

- Если база данных не была загружена, сохранение блокируется проверкой `CheckLoaded()`.
- Ошибки доступа к файлу (например, если `.xls` открыт в Excel) перехватываются блоком `try-catch`.
