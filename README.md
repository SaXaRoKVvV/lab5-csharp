# Задание 1. Чтение базы данных из Excel-файла

### Текст задачи

Прочитать базу данных из Excel-файла в объекты классов.

### Алгоритм решения

1. Метод `ExcelService.Load(path)` открывает файл через `WorkbookFactory.Create`.
2. По очереди читаются листы «Магазин», «Товар» и «Движение товаров», начиная со второй строки (первая строка содержит заголовки).
3. Каждая строка превращается в объект `Shop`, `Product` или `Movement` и добавляется в список класса `Database`.
4. Пустые строки пропускаются, текстовые значения обрезаются (в единицах измерения встречается «мл » с пробелом).

### Проверка входных данных

- Если файла нет, выбрасывается `FileNotFoundException`, если нет нужного листа, то `Exception` с названием листа. Обе ошибки перехватываются в меню и выводятся сообщением.
- Ввод: путь можно не вводить, при нажатии Enter берётся `LR5-var10.xls`.

### Тестирование

| Ввод | Результат |
|---|---|
| Enter | загружено: движений - 9720, магазинов - 18, товаров - 60 |
| несуществующий файл | сообщение «Файл не найден» |

# Задание 3. Удаление элемента по ключу

### Текст задачи

Удалить элемент из выбранной таблицы по ключу.

### Алгоритм решения

1. Ключ зависит от таблицы: ID операции (число), ID магазина (строка, например `M5`), артикул (число).
2. Для магазина и товара сначала проверяется через `Any`, нет ли на них ссылок в таблице движений. Если есть, удалять нельзя, чтобы не нарушить связи.
3. Удаление выполняется методом `RemoveAll` с условием по ключу, результат показывает, найден ли элемент.

### Проверка входных данных

- Числовые ключи проверяются на целое число, строковый ключ не может быть пустым.
- Если элемента с таким ключом нет, выводится сообщение.

### Тестирование

| Ввод | Результат |
|---|---|
| движение, ID `1` | элемент удалён |
| движение, ID `100000` | элемент с таким ключом не найден |
| магазин `M5` | нельзя удалить, есть ссылки в таблице движений |
| товар `abc` | ошибка, повторный ввод |

# Задание 4. Добавление элемента

### Текст задачи

Добавить элемент в выбранную таблицу.

### Алгоритм решения

1. Пользователь выбирает таблицу и по очереди вводит все поля.
2. Перед добавлением проверяется уникальность ключа через `Any`.
3. Для операции дополнительно проверяется, что указанные магазин и товар существуют.
4. Объект создаётся через конструктор и добавляется в список.

### Проверка входных данных

- Дата вводится строго в формате `дд.мм.гггг`, тип операции выбирается цифрой (1 - Поступление, 2 - Продажа).
- Количество упаковок - целое число не меньше 1, количество в упаковке и цена - положительные числа.
- Пустые строки не принимаются, дубликаты ключей и несуществующие ссылки отклоняются.

### Тестирование

| Ввод | Результат |
|---|---|
| магазин `M19`, район `Южный`, адрес `Заводская, 1` | элемент добавлен |
| магазин `M1` (уже есть) | такой ID уже существует |
| операция с магазином `M99` | магазина с таким ID нет |
| дата `31.02.2023` | ошибка, повторный ввод |

# Задание 5.3. Запрос к трём таблицам (перечень)

### Текст задачи

Вывести товары указанного отдела, проданные в магазинах указанного района, и количество проданных упаковок каждого товара.

### Алгоритм решения

1. Метод `GetSoldProductsByDepartment` использует все три таблицы.
2. Продажи соединяются (`Join`) с магазинами, остаются нужный район, затем соединяются с товарами и остаётся нужный отдел.
3. `GroupBy` по наименованию товара, `Select` формирует строку «название: количество уп.» через `Sum`.
4. `OrderBy` сортирует результат по алфавиту.

### Проверка входных данных

- Отдел и район не могут быть пустыми. Если ничего не найдено, выводится «Найдено товаров: 0».

### Тестирование

# Задание 5.4. Запрос к трём таблицам (значение)

### Текст задачи

Определить общий объём (в литрах) всех видов шампуней для волос, проданных магазинами, расположенными на улице Гагарина, за период с 14 по 22 июля включительно. В ответ записать целую часть числа. (Запрос из примера, сделан обобщённым: название товара, улица и период вводятся с клавиатуры.)

### Алгоритм решения

1. Метод `GetSoldVolumeInLiters` использует все три таблицы.
2. Из движений берутся продажи за период, сравниваются только даты без времени (`Date`), границы включаются.
3. `Join` с магазинами, у которых адрес содержит нужную улицу, затем `Join` с товарами, у которых единица измерения «мл» и в названии есть нужный текст.
4. Для каждой продажи считается объём: упаковки * количество в упаковке. `Sum` складывает, деление на 1000 переводит миллилитры в литры.
5. В меню выводится целая часть числа.

### Проверка входных данных

- Название и улица не могут быть пустыми, даты вводятся в формате `дд.мм.гггг`, дата начала не может быть позже даты окончания.

### Тестирование

| Ввод | Результат |
|---|---|
| `Шампунь`, `Гагарина`, 14.07.2023, 22.07.2023 | 855 л (совпадает с ответом из задания) |
| `Шампунь`, `Гагарина`, 22.07.2023, 14.07.2023 | сообщение об ошибке дат |
| `Шампунь`, `Несуществующая`, 14.07.2023, 22.07.2023 | 0 л |

# Задание 6. Сохранение изменений в Excel-файле

### Текст задачи

Сохранить изменения, сделанные в базе данных, в Excel-файл.

- Если база не загружена, сохранение не выполняется. При нажатии Enter файл сохраняется по текущему пути, можно указать другой.
