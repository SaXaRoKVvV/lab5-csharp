Код оформлен по руководству по стилю C# от Microsoft. Все данные, вводимые с клавиатуры, проверяются на корректность.

# 2. Удаление элементов (по ключу)

### Текст задачи

Реализовать удаление элемента из выбранной таблицы по первичному ключу.

### Алгоритм решения

1. Пользователь выбирает таблицу (`Магазин`, `Товар` или `Движение товаров`) и вводит значение первичного ключа (`ID`, `Артикул` или `ID операции`).
2. Методы `DeleteShop`, `DeleteProduct` и `DeleteMovement` в `QueryService` ищут запись через LINQ (`FirstOrDefault`).
3. Для таблиц `Магазин` и `Товар` перед удалением выполняется проверка ссылочной целостности через `Any`: если в таблице `Движение товаров` есть операции с этим ключом, удаление отменяется.
4. Если ссылок нет, объект удаляется из списка через `Remove`.

### Проверка входных данных

- Попытка удалить несуществующий ключ выводит сообщение, что запись не найдена.
- Попытка удалить магазин или товар, задействованный в движениях, блокируется с пояснением причины.
